# 🛍️ E-commerce Sales Analyzer

## 📌 About the Project
An interactive sales analysis dashboard developed using Python and Streamlit. This project helps explore e-commerce sales data and understand product performance through visualizations.

## 🎯 Project Objectives
- Analyze product-wise sales.
- Identify top-performing products.
- Understand sales and quantity trends.
- Explore business data through interactive filters.
- Present insights using charts and metrics.

## 🛠️ Technologies Used
- Python
- Streamlit
- Pandas
- CSV Dataset

## ✨ Key Features
- Interactive sales dashboard
- Sales data visualization
- Product filtering
- CSV file upload
- Revenue summary
- Product performance analysis

## 🚀 How to Run

1. Install Python.
2. Install the required libraries:

```bash
pip install streamlit pandas
```

3. Run the application:

```bash
streamlit run app.py
```

## 📊 Dataset
The project uses an e-commerce sales dataset containing:
- Product
- Category
- Sales
- Quantity
